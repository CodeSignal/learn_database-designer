Overview

The DB Schema Designer lets you sketch a database schema: create tables, add fields, mark keys, and connect tables with foreign keys. Everything happens on the canvas; buttons appear next to whatever you select.

  • Click a table to select it. A toolbar appears above it.
  • Click a field to select it. Buttons appear at the end of its row.
  • Click the empty background to clear the selection.

Moving Around the Canvas

  • Zoom: use the mouse wheel or trackpad scroll. The view zooms around your cursor.
  • Pan: drag the empty background.
  • Move a table: drag the dotted handle at the right of the table header. This is the only place you can drag a table from.

Tables

Create a table

  1. Click the + button in the top-left corner of the canvas.
  2. Enter a table name and pick a starting color.
  3. Click Create Table or press Enter.

The new table is placed in the first free spot on the canvas. If the name is already used, a number is added (for example users_1).

Edit a selected table

Click a table to show its toolbar:

  • Color swatches (white, blue, green, red) – click one to recolor the table header. The current color is circled.
  • Pencil – opens a pop-up where you can rename the table and change its color. Names must be unique.
  • Trash – deletes the table after you confirm. Any foreign keys from or to the table are removed too.

Fields

Add a field

  1. Click + Add field at the bottom of a table.
  2. Fill in the pop-up:
    • Column name (required)
    • Type: int, bigint, decimal(10,2), varchar(255), text, date, timestamp or boolean
    • Nullable – whether the field may be empty
    • Default – optional default value
    • Primary key and Unique (see below)
  3. Click Add Field or press Enter.

If a field with the same name already exists in the table, a number is added to the new name.

Edit or delete a field

Click a field to select it. Its row is highlighted and three buttons appear:

  • Link – set up a foreign key for this field (see Foreign Keys).
  • Pencil – edit the field in the same pop-up used to add it.
  • Trash – delete the field after you confirm. Its keys and any foreign keys from or to it are removed too.

Each field is shown as name: type, followed by NOT NULL when the field isn't nullable.

Primary & Unique Keys

  • Tick Primary key in the field pop-up to make the field part of the table's primary key. Primary key fields are always NOT NULL and are marked with 🔑.
  • Tick Unique to add a unique constraint on that single field.

Foreign Keys

Add a foreign key

  1. Click the field the key starts from (for example orders.user_id).
  2. Click its link button.
  3. Choose the To table and To column it refers to. The pop-up suggests another table and its primary key.
  4. Pick an On Delete action: NO ACTION, CASCADE, SET NULL or RESTRICT.
  5. Click Add FK.

An arrow is drawn from the field to the column it refers to, and both fields are marked with 🔗.

Change or remove a foreign key

Select the field and click its link button again. The pop-up shows the field's foreign keys in the Key list. Pick one, change its settings and click Save FK, or click Remove FK to delete just that key. Choose + New foreign key to add another one. Other keys on the field are never changed.

How arrows are drawn

Arrows pick the sides of the tables automatically, so you can arrange tables however you like:

  • If the target table is to the right, the arrow goes from the right side of the source to the left side of the target, and the other way round when it's to the left.
  • If one table is above the other, the arrow leaves and enters on the same side and curves around the tables.
  • A table that refers to itself (for example employees.manager_id → employees.id) gets a small loop on its right side.

Arrows update as you drag tables around.

Saving

Your work is saved automatically as you go, so you don't need to save anything yourself.

Your solution is saved locally so that Cosmo can evaluate it. It will be deleted if you reset the session, or if the session resets because you've been inactive for too long.

Shortcuts

  • Enter – confirm the pop-up while typing in a text box (name, default)
  • Esc – close the open pop-up or this help window without changes
  • Mouse wheel – zoom in/out
  • Drag background – pan the canvas
  • Drag the dotted handle – move a table
  • Click table / field – select it
  • Click background – clear the selection
  • Tab / Shift+Tab – move between tables, fields and their buttons
  • Enter or Space – select the focused table or field, or press the focused button

Troubleshooting / FAQ

I can't see the buttons for a field

The link, pencil and trash buttons only appear on the selected field. Click the field's text inside the table to select it.

How do I rename a table?

Click the table, then click the pencil button in the toolbar above it.

How do I delete a table?

Click the table, then click the trash button in the toolbar above it. This also removes any foreign keys connected to the table.

I can't drag a table

Tables can only be dragged by the dotted handle at the right of their header. Dragging anywhere else on the canvas pans the view.

A new table doesn't appear

New tables are placed in the first free spot from the top-left of the diagram. If you have panned or zoomed far away, drag the background back towards the top-left to find it.

Is my work saved automatically?

Yes, every change is saved as you make it. Resetting the session, or being inactive long enough for it to reset, deletes your solution. See Saving.
